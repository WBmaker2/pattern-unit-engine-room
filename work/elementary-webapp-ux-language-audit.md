# Elementary Learner Language Audit

## 감사 방법

- `work/elementary-webapp-ux-language-candidates.md`의 후보 문장을 원문 파일에서 다시 확인하고, 테스트용 문자열·내부 식별자·개발 문구는 학습자 문장으로 세지 않았다.
- `references/child-language-rubric.md`의 한 문장 한 행동, 구체적인 동사, 짧은 낱말 기준과 `references/learner-text-audit-workflow.md`의 before/after/probe 구조를 사용했다.
- 대상 독자는 초등 1~2학년이며, 한 번에 읽을 수 있는 두 줄 이내를 기본으로 한다.

## 유지할 표현

- `다시 해 봐요`, `가장 짧은 한 묶음을 찾았어요`, `모양은 달라도 같은 순서예요`는 짧고 행동/학습 증거가 분명하므로 유지한다.
- `선택한 칸에 들어갈 모양을 다시 골라요`, `서로 다른 항에는 서로 다른 새 모양을 골라요`는 오답 이유와 다음 행동이 함께 있어 유지한다.
- 내부 용어 `mappingComplete`, 미션 ID, `retry`와 같은 구현 단어는 화면에 노출하지 않는다.

## 문장 합격 조건

1. 새 문장은 학생에게 선택할 대상과 다음 행동을 한 번에 알려 준다.
2. 숫자에는 항상 무엇을 세는지 명사를 붙인다.
3. 음성 안내가 꺼져도 같은 의미가 화면에 남는다.
4. 문장 변경은 판정 규칙, 버튼 disabled 조건, 기존 피드백의 긍정적 어조를 바꾸지 않는다.
